# Guerra de Facciones

Juego de cartas de estrategia de la marca **Estandartes Eternos**.

- `index.html`: el juego.
- `cartas/base.json`: las cartas del set base (con rutas a las imágenes).
- `img/`: portada, logo, efectos visuales y arte de las cartas, separado por facción en `img/facciones/<facción>/`.
